# Исторические материалы — не текущие инструкции

`REPORT.md.txt`, `REPORT-phase2.md.txt`, `TESTING-GUIDE.md.txt` и `e2e*.py.txt` сохранены как исходные исторические артефакты. Расширение `.txt` намеренно: команды и HTTP-скрипты **не предназначены для запуска при проверке публикации**.

Они содержат локальные пути прежнего окружения, публичные демо-учётные данные и описания ledger-операций. Секреты провайдеров/JWT/сырые результаты не включены. Исходные result JSON и venv остались вне Git. Исторические результаты не являются новыми воспроизведёнными утверждениями. Некоторые утверждения устарели (APPA-контейнер теперь остановлен) или не подтверждают путь настоящего поиска (см. docs/LIMITATIONS.md).

Текущие инструкции: `../../docs/DEPLOYMENT.md`, `../../docs/VALIDATION.md`. Не выполнять банковские E2E на основном стенде. Для offline-проверки используйте `../validation.py` и fake-executor тесты.
